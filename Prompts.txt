Requirements:

3. Process every N-th frame (e.g., every 5th frame) to keep processing efficient.

Prompt 3: Road State Aggregator & PCI Calculation Engine
Act as a Civil/Software Engineer. Write a module `/vision/pci_engine.py` that converts YOLO defect metrics into a standardized Pavement Condition Index (PCI) and State Vector for Reinforcement Learning.

Requirements:
1. Define a function `calculate_pci(defects_dict)` that computes PCI starting from 100:
   PCI = 100 - (digs * 12 + patches * 8 + cracks * 4 + potholes * 15)
   Ensure PCI is capped between 0.0 and 100.0.
2. Define a function `build_rl_state(pci, defects_dict, road_age_years)` that formats the vector:
   `np.array([PCI, digs, patches, cracks, road_age_years], dtype=np.float32)`.
3. Include unit tests at the bottom of the file to verify PCI calculation edge cases (e.g., zero defects = 100 PCI, heavy defects = 0 PCI).



Prompt 4: Custom Gymnasium Environment for Road Maintenance
Act as a Reinforcement Learning Engineer. Build a custom Gymnasium environment in `/rl_engine/road_env.py` for road maintenance policy optimization.

Requirements:
1. Inherit from `gymnasium.Env`.
2. Define `action_space` as `Discrete(3)`:
   - 0: Do Nothing
   - 1: Preventive Repair (Fix digs/patches, costs 15 points, restores 20 PCI)
   - 2: Major Resurfacing (Restores PCI to 100, resets defects to 0, costs 60 points)
3. Define `observation_space` as `Box(low=[0, 0, 0, 0, 0], high=[100, 50, 50, 50, 30], dtype=np.float32)` representing [PCI, Digs, Patches, Cracks, Road Age].
4. Implement `step(action)`:
   - Degrade road condition each step based on current defect density and age.
   - Calculate rewards: reward high PCI, heavily penalize PCI < 40 (-50 penalty), and subtract action execution costs.
   - Set `done = True` if PCI <= 0 or Road Age >= 15 years.
5. Implement `reset()` returning initial default road state.
